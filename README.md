# 🤖 HAUSDORFF CRM — בוט טלגרם

## סוכן AI להזנת אנשי קשר ונכסים ל-CRM דרך טלגרם

שלח הודעה חופשית בעברית → הסוכן מפרק אותה לנתונים → שומר ב-CRM

---

## מדריך התקנה — צעד אחר צעד

### שלב 1: יצירת בוט בטלגרם (5 דקות)

1. פתח את אפליקציית **טלגרם** בטלפון שלך
2. חפש את **@BotFather** (זה בוט רשמי של טלגרם)
3. שלח לו: `/newbot`
4. הוא ישאל **שם לבוט** — כתוב: `Hausdorff CRM`
5. הוא ישאל **username** — כתוב: `hausdorff_crm_bot` (אם תפוס, נסה `hausdorff_crm_123_bot`)
6. הוא ישלח לך **טוקן** שנראה ככה: `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
7. **שמור את הטוקן** — תצטרך אותו בשלב 3

### שלב 2: הגדרת Railway (10 דקות)

1. היכנס ל-[Railway](https://railway.app) — אתה כבר מחובר שם
2. לחץ על **New Project** → **Deploy from GitHub repo**
3. בחר את הריפוזיטורי **hausdorff-telegram-bot** (תצטרך להעלות את הקוד ל-GitHub קודם — ראה שלב 2.5)
4. Railway יזהה את הפרויקט ויתחיל לבנות

### שלב 2.5: העלאת הקוד ל-GitHub

1. היכנס ל-[GitHub](https://github.com) → לחץ על **+** → **New repository**
2. שם: `hausdorff-telegram-bot`
3. לחץ **Create repository**
4. העלה את 3 הקבצים: `bot.js`, `package.json`, ו-`README.md`
   - ב-GitHub לחץ על **uploading an existing file**
   - גרור את הקבצים ולחץ **Commit changes**

### שלב 3: הגדרת משתני סביבה ב-Railway

ב-Railway, לחץ על הפרויקט → **Variables** → הוסף את המשתנים הבאים:

| שם המשתנה | ערך | חובה? |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | הטוקן שקיבלת מ-BotFather | כן |
| `CRM_API_URL` | `https://hausdorff-crm-backend-production.up.railway.app` | כן |
| `CRM_EMAIL` | `rafi@hausdorff.co.il` | כן |
| `CRM_PASSWORD` | הסיסמה שלך ל-CRM | כן |
| `ANTHROPIC_API_KEY` | מפתח API של Anthropic (ראה שלב 4) | מומלץ |
| `ALLOWED_TELEGRAM_IDS` | מזהה הטלגרם שלך (ראה שלב 5) | מומלץ |

### שלב 4: מפתח Anthropic API (אופציונלי אבל מומלץ)

המפתח הזה מפעיל את הפרסור החכם — הבוט מבין טקסט חופשי בעברית.
בלי המפתח, הבוט עדיין עובד אבל עם פרסור בסיסי יותר.

1. היכנס ל-[console.anthropic.com](https://console.anthropic.com)
2. הירשם / התחבר
3. לחץ על **API Keys** → **Create Key**
4. העתק את המפתח והכנס ל-Railway כ-`ANTHROPIC_API_KEY`

עלות: כל הודעה עולה כ-0.01$ (אגורה אחת) — זניח

### שלב 5: הגבלת גישה לבוט (מומלץ!)

כדי שרק אתה תוכל להשתמש בבוט:

1. פתח טלגרם, חפש את הבוט שיצרת ושלח לו: `/id`
2. הוא ישלח לך מספר — זה המזהה שלך
3. ב-Railway, הוסף משתנה: `ALLOWED_TELEGRAM_IDS` = המספר שקיבלת
4. אם רוצה להוסיף גם את השותף: `ALLOWED_TELEGRAM_IDS` = `12345678,87654321` (מופרד בפסיקים)

## איך משתמשים?

### הוספת איש קשר

שלח הודעה חופשית, למשל:

```
יוסי כהן 054-1234567 משקיע תקציב עד 5M מחפש חנויות בבאר שבע
```

הבוט יחזיר:
```
👤 איש קשר חדש

שם: יוסי כהן
טלפון: 054-1234567
סוג: משקיע
תקציב: עד 5,000,000 ₪
אזורים: באר שבע
סוגי נכסים: חנות

האם הנתונים נכונים?
[✅ אישור ושמירה] [❌ ביטול]
```

### הוספת נכס

שלח הודעה שמתחילה ב- `/נכס`:

```
/נכס חנות 85 מר גני אביב באר שבע 12000 שח לחודש מעטפת חזית 8 מטר
```
