# 🤖 HAUSDORFF CRM Bot v6.0

בוט טלגרם פרואקטיבי ל-CRM נדל"ן מסחרי. מעבר מבוט שמגיב לבוט שיוזם.

## 🆕 חדש בגרסה 6

### 1. בעל נכס → רישום נכס אוטומטי
כשנשמר איש קשר מסוג **"בעל נכס"**, הבוט מציע מיד:
> 🏢 *יוסי כהן* הוא בעל נכס. לרשום עכשיו את הנכס שלו?
> [🔑 השכרה] [💰 מכירה] [❌ לא עכשיו]

לחיצה על השכרה/מכירה פותחת ויזרד נכס עם `owner_id` ו-`deal_type` כבר מוזנים.

### 2. קישוריות מלאה בין ישויות
- **נכס** → מקושר לפרויקט (`project_id`) + לבעלים (`owner_id`)
- **משימה** → מקושרת לאיש קשר (`contact_id`) + לנכס (`property_id`)
- **פגישה** → מקושרת לאיש קשר (`contact_id`) + לנכס (`property_id`)

הבחירה דרך כפתורים: 6 הישויות האחרונות + אפשרות לדלג.

### 3. פגישות (חדש 📅)
מודול חדש לפגישות עם:
- כותרת, תאריך, **שעת התחלה**, **משך** (30/45/60/90/120 דק׳)
- מיקום (במשרד / אצל הלקוח / בנכס / זום / חופשי)
- קישור לאיש קשר ולנכס
- הערות

יוצר רשומה ב-`/api/meetings` (`start_datetime` + `end_datetime`). אם נכשל, fallback לרשומת task מסוג "פגישה".

### 4. שעה למשימות, פגישות, שיחות
כל משימה ופגישה מקבלות שעה מדויקת. תזכורת תישלח בדיוק באותה דקה.

### 5. תזכורות פרואקטיביות (מתוך המערכת)
הבוט עוקב אחרי כל המשימות ב-CRM ושולח התראות אוטומטיות:

| שעה | פעולה |
|-----|-------|
| **09:00** | 🌅 *סיכום בוקרי* — רשימת משימות היום + משימות באיחור |
| **12:00** | ☀️ *תזכורת שנייה* — משימות שעדיין פתוחות |
| **18:00** | 🌆 *סיכום ערב* — בוצע / לא בוצע היום |
| כל דקה | ⏰ תזכורת ייעודית כשמגיעה שעת המשימה |

### 6. כפתורי פעולה אינטראקטיביים
כל תזכורת מגיעה עם:
- ✅ **בוצע** — מסמן `completed=1` ב-CRM
- ⏰ **דחה למחר** — מעדכן `due_date` + מוסיף `postponed_reason`

### 7. פקודות חדשות
- `/today` — משימות פתוחות להיום
- `/pending` — כל המשימות הפתוחות + כפתורי בוצע/דחה
- `/summary` — סיכום יומי

### 8. תפריט ראשי מורחב
```
👤 איש קשר      🏢 נכס
📋 משימה        📅 פגישה
🏗️ חברה        📊 משימות היום
```

## 📁 מבנה הפרויקט (שטוח, ללא תיקיות)

| קובץ | תיאור |
|------|-------|
| `bot.js` | ניתוב ראשי + callbacks גלובליים |
| `config.js` | הגדרות (BOT_VERSION = 6.0.0) |
| `helpers.js` | עזרי תאריך/שעה + `fmtMeeting` |
| `crm.js` | API: create/update/list לכל הישויות |
| `parser.js` | פירוק טקסט בעברית עם Claude Sonnet |
| `questionnaire.js` | מנוע שאלון גנרי + תמיכה ב-`buildButtons` דינמי |
| `picker.js` | **חדש** — כפתורי בחירת ישויות קיימות (6 אחרונות) |
| `contacts.js` | אנשי קשר + הצעת רישום נכס לבעלים |
| `properties.js` | נכסים + קישור לפרויקט/בעלים + entry point `startWithOwner` |
| `tasks.js` | משימות + שעה + קישור לאיש קשר/נכס |
| `meetings.js` | **חדש** — פגישות מלאות |
| `reminders.js` | מנוע 09:00/12:00/18:00 + פר-משימה + handlers |
| `start.js` | `/start /help /id /today /pending /summary` |

## 🔌 דרישות backend (REST API)

הבוט צורך את ה-endpoints הבאים. כולם כבר קיימים ב-CRM:

```
POST   /api/auth/login
POST   /api/contacts        GET /api/contacts        PUT /api/contacts/:id
POST   /api/properties      GET /api/properties      PUT /api/properties/:id
POST   /api/tasks           GET /api/tasks           PUT /api/tasks/:id
POST   /api/companies       GET /api/companies
POST   /api/meetings        GET /api/meetings
GET    /api/projects
```

PUT על משימות תומך ב: `completed`, `completion_notes`, `due_date`, `postponed_reason`.

## 🧠 איך עובדת ה"פרואקטיביות"

הבוט פועל בשתי דרכים:

1. **תגובה** (כמו תמיד) — סוכן כותב, בוט עונה
2. **יוזמה** (חדש) — הבוט מתעורר לבד:
   - בוקר 09:00 → "הנה המשימות שלך להיום"
   - צהריים 12:00 → "עדיין יש פתוחות, אל תשכח"
   - שעת משימה → "⏰ זה הזמן! [✅ בוצע] [⏰ דחה]"
   - ערב 18:00 → "סיכום: בוצעו X, נשארו Y"

המנגנון: `setInterval` כל דקה (`REMINDER_CHECK_INTERVAL`). מנגנון אנטי-כפילות מוודא שכל הודעה נשלחת פעם אחת ביום.
